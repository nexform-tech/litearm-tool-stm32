## 迁移边界

### 复用，不重写

| 领域 | 规则 |
| --- | --- |
| 串口所有权 | 唯一所有者线程持有 SDK 与串口。点动/停止的接管是**只写旁路**，与急停同一类通道；GUI 线程绝不读串口。 |
| 激活 | 移植 studio 的客户端契约：许可证记录形状、注册校验、服务错误码、同意书。工具唯一出网点。 |
| DFU | DfuSe 引擎与镜像流水线从 studio/上游 `dfu-flash` 原样复制。任何时序改动先回改上游。 |
| 夹爪 | 移植 studio 的会话、标定与 CAN 适配器；不重写夹爪协议。仅 Linux。 |
| 日志 schema | 保持 studio 的 OpenTelemetry 字段名与 JSONL 布局，`jq`/Loki/Fluent Bit 不改即可读。不要引入 FastAPI/WebSocket。 |
| 3D 资产 | 用 `litearm-description` 的 URDF/网格与 studio 的抽稀/LOD 流程；工具内不引入 Node/pnpm 构建链。 |

### 明确不迁

| 项 | 决定 |
| --- | --- |
| Tauri/React 前端 | 由 PyQt 页面替代；Web UI 不迁。 |
| FastAPI 守护进程与 WebSocket 协议 | 不迁；工具是单进程 + 一个 SDK 所有者线程。 |
| 浏览器遥测存储与保留策略 | 不迁；工具以 100Hz 环形缓冲与 300Hz 固件采集为数据源。 |
| QtWebEngine / 内嵌浏览器 | 排除。 |
| VR 运行时与渲染 | 留在 `litearm-vr-studio`；工具不承载 VR。 |
| Studio 的 Web i18n 栈 | 不迁；issue #12 用 Qt 翻译或字符串表。 |
| 主题切换 | 暂不迁；有需求再加。 |
